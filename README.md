# To-Do List Application

To-Do List Application is a simple and interactive web-based application designed to help users manage and organize their daily tasks efficiently.
The application allows users to add, update, mark, and delete tasks through a clean and user-friendly interface, making task management easy and convenient.
This project focuses on frontend web development concepts, dynamic user interaction, and DOM manipulation while demonstrating practical implementation of JavaScript functionality and responsive UI design.

Tools & Technologies Used: HTML, CSS, JavaScript, VS Code.
